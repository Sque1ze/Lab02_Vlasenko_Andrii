**Тема:** Тривалість життя та економічний добробут країн світу, 1952–2007.

## Що зроблено

Досліджено реальний історичний датасет **Gapminder**: **142 країни × 12 років = 1704 спостереження**. Ціль `lifeExp` — очікувана тривалість життя при народженні (років), неперервна числова змінна. Фактори: `gdpPercap` (ВВП на душу), `year` (рік), `continent` (континент), `pop` (населення). `country`, `iso_alpha`, `iso_num` — географічні/технічні ідентифікатори; **не включайте коди до кількісних кореляцій**. Одиниця спостереження — **країна-рік**, а не окрема людина.

Проведено: огляд структури, перевірку пропусків/дублікатів/аномалій, описову статистику, одно-, дво- і багатовимірний EDA, аналіз змін у часі, факторів доходу й регіону, а також порівняння країн. Регресійні моделі **не навчалися** — це відповідає актуальній умові.

## Як запустити на Windows 11 (PowerShell)

1. **Розпакуйте весь архів** `Lab02_Vlasenko_Andrii.zip` — не переміщуйте тільки `.ipynb` без `data/`.
2. У PowerShell перейдіть **у корінь розпакованої папки** `Lab02_Vlasenko_Andrii`.
3. Виконайте команди:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m notebook
   ```

4. У вкладці Jupyter відкрийте `notebooks/EDA.ipynb`, далі **Kernel → Restart & Run All**. Комірки мають запуститися зверху вниз. Якщо Jupyter відкривається не з тієї папки, змініть поточну директорію на корінь архіву та повторіть запуск.
5. Перевірте створені CSV у `data/processed/` та `outputs/tables/`, PNG у `outputs/figures/`.
6. Для захисту відкрийте **`reports/Presentation.pptx`** у Microsoft PowerPoint / LibreOffice Impress. Текст доповіді та відповіді — `reports/defense_script.md`.

**Примітка:** Notebook уже містить **збережені вихідні результати, таблиці й графіки**. Можна подивитися його без виконання комірок. Для повторного запуску використовуйте наведені команди. Після запуску PPTX автоматично не перебудовується: у презентації наведено фіксовану перевірену версію графіків з цього архіву; якщо зміните вихідні дані, презентацію потрібно оновити окремо.

## Що саме збережено

У `outputs/tables/`: `data_quality.csv`, `outlier_review.csv`, `descriptive_statistics.csv`, `category_frequencies.csv`, `year_summary.csv`, `group_comparison.csv`, `group_comparison_2007.csv`, `correlations.csv`, `within_year_correlations.csv`, `within_continent_correlations_2007.csv`, `income_terciles_2007.csv`, `country_changes.csv`.

Основні числа: **0** пропусків і дублікатів, `lifeExp` (незважене середнє країн) **49.1 року** у 1952 році та **67.0** у 2007, кореляція Пірсона у зрізі 2007 між `lifeExp` і `log10(gdpPercap)` **r ≈ 0.809**. Кожен висновок можна простежити до таблиць, коду й графіків.
